# Contributing

Bug reports, documentation corrections, and feedback about the public contract
are welcome. Code contributions are temporarily paused until the project has a
reviewed contributor agreement.

Before reporting an issue, run:

```bash
python scripts/verify_public_export.py
python -m unittest discover -s tests -v
```

Do not attach private DaemonState source, real coding-session content, customer
data, credentials, database files, unredacted logs, or production configuration.
